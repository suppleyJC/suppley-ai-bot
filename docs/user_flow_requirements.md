# Fluxo de Trabalho do Sistema SUPPLEY Calc

## Requisitos do Usuário (pasted_content_2.txt)

### Objetivo Principal
A ferramenta deve ser funcional, com banco de dados vinculado para armazenar:
- Cálculos das cotações
- Clientes e indústrias no exterior e Brasil
- Base de dados para a IA (Excambia)

### Fluxo de Trabalho

**Fase 1 - Identificação e Sourcing**
1. Identificação/conformação automática da NCM via IA
2. Mapeamento das indústrias mais adequadas globalmente
3. Disparo de cotações multicanal (e-mail, WhatsApp, WeChat)

**Fase 2 - Negociação e Validação**
4. Recebimento e consolidação de propostas das fábricas
5. Cálculo e validação automática de custos (cadeia completa EXW → Preço de Venda)
6. Precificação para revenda quando aplicável

**Fase 3 - Execução**
7. Realização do pedido
8. Processamento de pagamentos e câmbio
9. Acompanhamento de carregamento/frete internacional

**Fase 4 - Nacionalização e Entrega**
10. Desembaraço aduaneiro
11. Disponibilização da mercadoria ao cliente

### Papel da Excambia (IA)
- Inteligência de Mercado
- Automação Operacional
- Análise Preditiva
